# CodeScope

**AI-powered Codebase Health & Intelligence for VS Code.**

CodeScope analyzes your project and gives you a living map of your codebase — surfacing performance issues, dead code, dependency risks, and architectural relationships.

## Features (Roadmap)

- 🗺️ **Codebase Explorer** — Navigate files, functions, and dependencies visually
- 🧹 **Dead Code Hunter** — Find unused functions, exports, and packages
- 📦 **Dependency Detective** — Analyze npm dependencies and import graphs
- ⚡ **Performance Analyzer** — Static analysis for JS/TS performance anti-patterns
- 🐛 **Variable Tracker** — Track variable value changes during debug sessions
- 🤖 **AI Assistant** — Ask natural language questions about your codebase

## Getting Started

1. Open any TypeScript/JavaScript project in VS Code
2. Click the CodeScope icon in the Activity Bar
3. Click **Analyze Project**
